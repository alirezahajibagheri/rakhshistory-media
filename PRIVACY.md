# Rakhshi uploader — Privacy Policy

_Last updated: November 1, 2026_

"Rakhshi uploader" is a private tool used only by the owner of the Rakhshi (@rakhshistory) YouTube channel to upload the channel's own videos.

- **Data accessed:** the app uses Google's YouTube Data API only to upload videos and set their titles, descriptions and tags on the owner's own channel.
- **No other users:** the app is not offered to the public and does not collect, store, sell or share data from anyone else.
- **Storage:** the only stored credential is the owner's OAuth refresh token, kept as an encrypted secret in the owner's private environment. No YouTube user data is stored.
- **Revoking access:** access can be revoked at any time at https://myaccount.google.com/permissions.
- **Contact:** rakhshistory@gmail.com

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
